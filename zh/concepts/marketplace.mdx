**Marketplace** 是 Octo 发现与分发[智能体能力](/zh/concepts/the-agent-model)的控制平面。
独立的 [`octo-marketplace`](https://github.com/Mininglamp-OSS/octo-marketplace)
服务将目录资产统一存为**插件**，支持四种类型：

| 插件类型 | 能力 |
|---|---|
| `skill` | 围绕 `SKILL.md` 打包的能力及其支持文件。 |
| `connector` | 连接描述，包括 MCP 服务器连接。 |
| `expert` | 专家定义。 |
| `expert_team` | 专家团定义及其关联关系。 |

<Info>
  本页依据 [octo-cli v0.19.5](https://github.com/Mininglamp-OSS/octo-cli/releases/tag/v0.19.5)
  与 [Marketplace v0.8.0](https://github.com/Mininglamp-OSS/octo-marketplace/releases/tag/v0.8.0)。
  [生成式 CLI 参考](/zh/reference/octo-cli)单独固定于 v0.18.0 的已收录子集，不枚举 Marketplace。
  已发布合同不能证明你的部署实际运行了哪个版本或采用了哪种审核策略。
</Info>

## Skill

**Skill** 是以根目录 `SKILL.md` 和可选支持文件打包的可复用能力。
由智能体运行时决定如何加载和使用已安装的能力。
创作方法参见[构建并发布 Skill](/zh/guides/bot-developers/publish-a-skill)。

统一目录增加了发现、版本快照与分发能力：

| 阶段 | 发生了什么 |
|---|---|
| **上传与解析** | 初始化上传，按返回的上传要求 PUT 归档，再触发解析并等待解析任务成功。 |
| **导入** | `plugin import` 使用已完成的解析任务。创建插件会保存草稿和版本快照，不会直接发布。租户写入接受 `private` 或 `space`，不再接受已退役的 `public` 值。 |
| **发布或审核** | 显式发布遵循插件可见性与空间审核策略。私有发布仍仅拥有者可见；空间发布可能立即完成，也可能需要空间拥有者或管理员批准。 |
| **更新** | 已发布的空间内容必须提交冻结的审核版本。直接 import/upsert 修改会被拒绝；保存可编辑插件不能代替发布。 |
| **下载** | `plugin download` 流式返回从附件树重建的 ZIP。用 `--output` 保存文件；不再返回旧式 `download_url` 加 `file_sha256` JSON。 |

保存、发布与审核的边界参见[发布到应用市场](/zh/guides/integrators/marketplace)。

## MCP

**MCP** 连接器描述智能体运行时可以连接的
[Model Context Protocol](https://modelcontextprotocol.io) 服务器。
使用 `plugin_type=connector` 发现它；MCP 连接是连接器的一种子类型，不是独立目录。

连接器包的根目录 `mcp.json` 包含 `mcpServers` 连接条目。
加入运行时前，先检查命令或 URL、传输方式以及必需的环境变量或请求标头。
MCP 连接器不使用 Skill ZIP 下载流程。

<Warning>
  在目录文档中，将消费者提供的密钥保留为 `${VAR}` 占位符。
  不要上传真实密钥，仅通过目标运行时批准的密钥机制提供真实值。
  目录发布或探测成功不代表连接可安全运行，也不要依赖旧目录的密钥脱敏行为。
</Warning>

`octo-cli marketplace mcp probe --data @connection.json` 仍用于
`streamable-http` 与 `sse` 连接。它会发起远程连接，但不持久化提交的配置，
并返回连接信息和工具列表。请检查响应中的 `is_ok` 值；HTTP 200 本身不代表探测成功。
不要仅为了验证连接配方而发送真实密钥。
Marketplace 不启动 `stdio` 命令；请在目标运行时验证这类连接。

## CLI

CLI v0.19.5 使用统一插件命令。运行详情或下载命令前，将 `PLUGIN_ID`
替换为实际标识符：

```bash
octo-cli marketplace plugin list --scene-code default --plugin-type skill
octo-cli marketplace plugin get --plugin-id 'PLUGIN_ID'
octo-cli marketplace plugin download --plugin-id 'PLUGIN_ID' --output ./skill.zip
octo-cli marketplace plugin list --scene-code default --plugin-type connector
```

旧的 `marketplace skill list`、`marketplace skill download` 和
`marketplace mcp list` 已在该客户端退役。目录列表需要 `--scene-code`，
通常还需要 `--plugin-type`；查看自己拥有的所有类型时可使用
`--scene-code default --mode mine`。列表分页返回，一页不是完整目录或完整拥有权检查。

CLI 使用当前凭据和空间上下文。对于 `bf_` 用户机器人，服务端解析其拥有者身份
以及机器人所属的权威空间。传入其他空间标头不会获得跨空间访问权限，
机器人也不会继承其拥有者的空间管理角色。

下载不会安装或执行 Skill。安装方必须检查归档、拒绝不安全路径与链接、
保留已有安装，并按运行时流程重新加载。解压时不要执行归档脚本。
不要期待 ZIP 端点返回已退役下载响应中的哈希字段。
