### `docs sheet edit`

Apply a batch sheet edit — cells, layout, filters, validation, and dropdowns (needs writer) · 🟠 写

```bash
octo-cli docs sheet edit <docId> [flags]
```

Applies one atomic spreadsheet batch under a mandatory optimistic-concurrency guard. Pass the base-version token from `docs sheet get` via --base-version (sent as If-Match); stale writes return 412 base_version_stale. Existing surfaces are cells, dims, drawings, hyperlinks, merges, and sheets. P0 worksheet resources are: freeze `&#123;logicalId:&#123;startRow,startColumn,xSplit,ySplit&#125;\|null&#125;`, filters `&#123;logicalId:&#123;ref:&#123;startRow,startColumn,endRow,endColumn&#125;,filterColumns?:[columns],enabledColumns?:[absoluteColumnIds]&#125;\|null&#125;`, and dataValidations `&#123;logicalId:[rules]\|null&#125;`. The public dataValidations and sheetDataValidations shapes are per-sheet arrays for every validation family, including list, listMultiple, and checkbox; do not send the internal flat `$&#123;logicalId&#125;!$&#123;uid&#125;` Y.Map shape except for the server-directed deletion-only repair described below. The server requires each rule uid to be unique within the sheet, 1–128 characters, free of `!` and control characters, plus at least one non-empty ranges entry. Checkbox ranges must not overlap another checkbox rule after the complete edit; list and listMultiple overlaps are accepted by the backend and should be sent only when intentional. For a working colored `list` or `listMultiple` dropdown, also send type, formula1 (JSON-serialized option labels), formula2 (the same number of comma-separated colors), showDropDown, and renderMode; omit operator. A listMultiple cell stores its selected labels as a JSON-array string, while a list cell stores the label directly. dataValidations is replace-style per logical sheet: read sheetDataValidations first and resend every rule to keep, but do not write if the deployed read surface omits any validation family on that sheet. null removes a freeze/filter/resource entry, and null or [] removes all validation rules for that sheet. An empty filterColumns array is omitted on readback. When enabledColumns is present it must be a non-empty list of absolute 0-based columns inside ref and select exactly which columns show filter buttons; every filterColumns colId must also appear in enabledColumns. A mismatch or enabledColumns:[] is rejected with 422 sheet_cell_invalid. The server deduplicates and sorts enabledColumns. For example, ref G:M with enabledColumns:[6,12] enables only G and M, not H-L. This controls filter-button visibility only, not read or write access; use protected ranges for access control. Filters are replace-style per logical sheet: read sheetFilters first and resend the complete filter object, including enabledColumns, when changing criteria. Omitting enabledColumns invokes legacy all-columns-in-ref behavior and silently widens the visible controls. An unfrozen freeze axis accepts startRow/startColumn 0 but normalizes it to -1. Sorting is a raw coordinate rewrite, not a spreadsheet-native sort: reorder the complete selected row block, carry each cell's complete &#123;v,f,s,p,t&#125; shape to its destination, and use null for destinations that become empty. The server stores `f` verbatim and does not re-anchor relative formula references; rewrite them for the destination or do not sort that range. Any state keyed by or containing coordinates stays at its old coordinates, including row dims, data-validation ranges, hyperlinks, merges, drawings, and cell-comment anchors; freeze panes and filter ranges/columns also remain fixed. Remap every affected resource for which you have an authoritative readable/writable surface, or do not sort the range. `sheetDims` is one workbook-level map whose keys may be sheet-qualified: `$&#123;logicalId&#125;:c&lt;idx&gt;` / `$&#123;logicalId&#125;:r&lt;idx&gt;` targets one tab, while bare `c&lt;idx&gt;` / `r&lt;idx&gt;` addresses the legacy default sheet; reads return keys exactly as stored. Bare and prefixed keys for the default sheet are separate entries; when migrating a legacy key, read sheetDims and clear the bare twin in the same batch, for example `&#123;"c0":null,"default:c0":200&#125;`. Rows hidden by an active shared filter still participate in a full rectangle rewrite. To sort only visible rows, evaluate `sheetFilters` criteria first and build a sparse permutation that leaves hidden row coordinates unchanged; clearing the filter does not preserve the visible subset. Any one surface may be the only non-empty batch member, but at least one surface must be non-empty. Only doc_type 'sheet' is accepted. Gates: validation-rule count over the max → 413 too_many_data_validations; cell/dim/drawing count over the max → 413 too_many_cells; worksheet-resource key count over the max → 413 too_many_sheet_resources; a single cell's payload too large → 413 cell_too_large; missing base version, malformed shape, or all batches empty → 400 invalid_body; a cell/dim/drawing/hyperlink/merge/tab/freeze/filter/data-validation violating its contract or key shape → 422 sheet_cell_invalid; writes intersecting a protected range → 403 protected_range. If 413 sheet_too_large includes baseVersion and repairDataValidationKey, submit only `&#123;"dataValidations":&#123;"&lt;repairDataValidationKey&gt;":null&#125;&#125;` with that base version, then retry. ### `docs sheet get`

Read a spreadsheet's live cells, worksheet resources, and base version (needs reader) · 🟢 读

```bash
octo-cli docs sheet get <docId> [flags]
```

Reads the LIVE flat cell map of a doc_type 'sheet' (keys `sheetId!row:col`, values &#123;v,f,s,p,t&#125;), column-width / row-height overrides (sheetDims), hyperlinks (sheetHyperLinks), merged ranges (sheetMerges), sheet tabs (sheetList), freeze panes (sheetFreeze), shared filters (sheetFilters), data-validation/dropdown rules (sheetDataValidations), and the base-version token that pins the read. Pass that token to `docs sheet edit` as --base-version so the optimistic-concurrency guard can prove the sheet did not change between read and write. Sorting is a raw coordinate rewrite, not a spreadsheet-native sort: reorder the complete selected row block, carry each cell's complete &#123;v,f,s,p,t&#125; shape to its destination, and use null for destinations that become empty. The server stores `f` verbatim and does not re-anchor relative formula references; rewrite them for the destination or do not sort that range. Any state keyed by or containing coordinates stays at its old coordinates, including row dims, data-validation ranges, hyperlinks, merges, drawings, and cell-comment anchors; freeze panes and filter ranges/columns also remain fixed. Remap every affected resource for which you have an authoritative readable/writable surface, or do not sort the range. `sheetDims` is one workbook-level map whose keys may be sheet-qualified: `$&#123;logicalId&#125;:c&lt;idx&gt;` / `$&#123;logicalId&#125;:r&lt;idx&gt;` targets one tab, while bare `c&lt;idx&gt;` / `r&lt;idx&gt;` addresses the legacy default sheet; reads return keys exactly as stored. Rows hidden by an active shared filter are still returned and a full rectangle rewrite includes them. To sort only visible rows, evaluate `sheetFilters` criteria first and build a sparse permutation that leaves hidden row coordinates unchanged; clearing the filter does not preserve the visible subset. doc / board / whiteboard bodies are a different Y.Doc shape and return 409 unsupported_doc_type here. A whole-sheet read over the 1 MB byte cap returns 413 sheet_too_large; pass --limit and follow nextCursor via --cursor. In paged mode every page is bounded by both --limit and the byte cap; sheetDims, sheetHyperLinks, sheetMerges, sheetList, sheetFreeze, sheetFilters, sheetDataValidations, and sheetConditionalFormats are returned on the first page only. When checkbox metadata exceeds the size or inspection budget, 413 includes baseVersion and repairDataValidationKey in the CLI error detail; delete that exact internal key with a validation-only PATCH and retry until the read succeeds. A --cursor whose snapshot moved returns 409 sheet_changed; a malformed --cursor returns 400 invalid_cursor; a non-positive --limit returns 400 invalid_limit. Also returns sheetConditionalFormats for conditional-format rule management. Use docs sheet list to discover persistent worksheet IDs/names, then choose exactly one of --sheet-id or --sheet-name to read only that worksheet. The backend filters cells and associated metadata before pagination and byte limits. Scoped responses carry sheetId; compact cursors retain that scope on subsequent requests, including cursor-only continuation. Missing or ambiguous names never fall back to all worksheets. The original baseVersion write token is unchanged.

| 参数 | 说明 |
|---|---|
| `<docId>` | 路径参数 |

**标志**

| 标志 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `--limit` | integer |  | max cells per page; opts into paged reads. Bounded by the server byte cap regardless. Omit for a whole-sheet read. |
| `--cursor` | string |  | opaque nextCursor from the previous page; also opts into paged reads. New compact cursors bind the document and selected worksheet; cursor-only continuation preserves that scope. Repeating an equivalent selector is allowed, changing scope is rejected. A cursor whose snapshot moved returns 409 sheet_changed. |
